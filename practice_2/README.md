# practice_2 — граф зависимостей пакетов apt

## 1. Описание
CLI-программа на Python. Этап 5: визуализация. Граф описывается на языке
D2 и сохраняется в SVG (через программу `d2`).

## 2. Функции и настройки
Опции см. этап 4. Теперь работает `-o`: рядом с `.svg` сохраняется
файл `.d2` с тем же именем. Стрелка идёт от пакета к тому, от кого он
зависит (в режиме `-R` тоже). Если `d2` не установлен, будет понятная
ошибка (код 1).

## 3. Сборка и тесты
Нужны Python 3.8+ и [d2](https://d2lang.com) в `PATH` (`d2 --version`).
Запуск: `./run.sh <опции>` или `run.bat <опции>`.
Тесты: `PYTHONPATH=src python3 -m unittest discover -s tests`.

## 4. Примеры
```
./run.sh -p curl -v <ВЕРСИЯ> -r <URL> -d 2 -o examples/curl.svg
./run.sh -p git  -v <ВЕРСИЯ> -r <URL> -d 2 -o examples/git.svg
./run.sh -p nano -v <ВЕРСИЯ> -r <URL> -d 3 -o examples/nano.svg
```
Результаты лежат в `examples/`.

## 5. Сравнение с apt-cache
Сравнивали с `apt-cache depends --recurse --no-recommends --no-suggests <пакет>`.

| Пакет | В depgraph | В apt-cache | Итог |
|---|---|---|---|
| curl | <N> | <N> | <кратко> |
| git | <N> | <N> | <кратко> |
| nano | <N> | <N> | <кратко> |

Причины расхождений: apt-cache показывает все альтернативы `a | b`
(мы только первую); виртуальные пакеты он выводит в `<>`; он читает все
индексы системы, а мы один `Packages`; версионные условия и архитектуры
мы отбрасываем.
