# practice_2 — граф зависимостей пакетов apt

## 1. Описание
CLI-программа на Python. Этап 4: добавлен режим обратных зависимостей,
то есть пакетов, которые зависят от заданного. Используется тот же BFS,
что и для прямых зависимостей.

## 2. Функции и настройки
Новая опция: `-R`, `--reverse` — вывести обратные зависимости.
Остальные опции см. этап 3. Глубина, фильтр и циклы работают так же.
В режиме `-R` строка `X -> A, B` значит «от X зависят A и B».
Для реального репозитория результат относится только к файлу `Packages`,
указанному в `-r`.

## 3. Сборка и тесты
Нужен Python 3.8+.
Запуск: `./run.sh <опции>` или `run.bat <опции>`.
Тесты: `PYTHONPATH=src python3 -m unittest discover -s tests`.

## 4. Примеры
```
./run.sh -p D -r tests/data/simple.txt -t -R -d 10
./run.sh -p E -r tests/data/simple.txt -t -R -d 10
./run.sh -p D -r tests/data/simple.txt -t -R -d 1
./run.sh -p A -r tests/data/cycle.txt -t -R -d 10
```
Вывод первой команды:
```
D -> B, C
B -> A
C -> A
A -> —
```
