# practice_2 — граф зависимостей пакетов apt

## 1. Описание
CLI-программа на Python. Этап 1: прототип с конфигурацией. Принимает
настройки из командной строки, проверяет их и выводит «ключ: значение».

## 2. Функции и настройки
| Опция | Смысл | По умолчанию |
|---|---|---|
| `-p`, `--package` | имя пакета (обязательно) | — |
| `-r`, `--repo` | URL репозитория или путь к тестовому файлу (обязательно) | — |
| `-t`, `--test-mode` | тестовый режим (`-r` — путь к файлу) | выкл |
| `-v`, `--version` | версия пакета (в тестовом режиме не нужна) | пусто |
| `-o`, `--output` | имя файла графа, только `.svg` | `graph.svg` |
| `-d`, `--depth` | максимальная глубина, от 1 | 3 |
| `-f`, `--filter` | подстрока для фильтрации пакетов | пусто |

Все параметры проверяются. При ошибке сообщение идёт в stderr, код 2.

## 3. Сборка и тесты
Сборка не нужна, нужен Python 3.8+.
Запуск: `./run.sh <опции>` или `run.bat <опции>`.
Тесты: `PYTHONPATH=src python3 -m unittest discover -s tests`
(PowerShell: `$env:PYTHONPATH="src"; python -m unittest discover -s tests`).

## 4. Примеры
```
./run.sh -p A -r tests/data/simple.txt -t -d 2 -f E
./run.sh -p a -r tests/data/simple.txt -t      # ошибка: имя пакета
./run.sh -p A -r nofile.txt -t                 # ошибка: файл не найден
./run.sh -p A -r tests/data/simple.txt -t -d 0 # ошибка: глубина
```
