# practice_2 — граф зависимостей пакетов apt

## 1. Описание
CLI-программа на Python. Этап 2: сбор данных. Скачивает индекс `Packages`
(`.gz` тоже можно) по URL и выводит прямые зависимости пакета заданной
версии. `apt` и сторонние библиотеки не используются, индекс разбирается
самой программой.

## 2. Функции и настройки
Опции те же, что на этапе 1. На этом этапе используются `-p`, `-r`, `-v`.

- Берутся поля `Depends` и `Pre-Depends`.
- Версионные условия `(>= 1.0)` и архитектуры `:any` отбрасываются.
- Из альтернатив `a | b` берётся первый вариант.
- Если пакет или версия не найдены, выводится ошибка (код 1).

## 3. Сборка и тесты
Нужен Python 3.8+ и интернет.
Запуск: `./run.sh <опции>` или `run.bat <опции>`.
Тесты: `PYTHONPATH=src python3 -m unittest discover -s tests`.

## 4. Примеры
Версию узнать: `apt-cache madison curl`.
```
./run.sh -p curl -v <ВЕРСИЯ> -r http://archive.ubuntu.com/ubuntu/dists/jammy/main/binary-amd64/Packages.gz
./run.sh -p curl -v 0.0 -r <URL>        # ошибка: версия не найдена
./run.sh -p nopackage -v 1 -r <URL>     # ошибка: пакет не найден
```
