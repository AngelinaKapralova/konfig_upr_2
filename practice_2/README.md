# practice_2 — граф зависимостей пакетов apt

## 1. Описание
CLI-программа на Python. Этап 3: строит граф транзитивных зависимостей
обходом в ширину (BFS) без рекурсии. Есть ограничение глубины, фильтр
по подстроке, защита от циклов и тестовый режим с файлом.

## 2. Функции и настройки
Используются `-p -r -t -v -d -f` (остальные опции см. этап 1).

- Пакеты на максимальной глубине попадают в граф, но не раскрываются.
- Пакеты с подстрокой фильтра в имени пропускаются.
- Каждый пакет раскрывается один раз, поэтому циклы не зацикливают программу.
- Пакеты вне индекса считаются листьями.
- Вывод: `пакет -> зависимости`, прочерк `—` значит «нет зависимостей».

Тестовый репозиторий (текстовый файл): `A: B C`, имена из больших
латинских букв, пакет без зависимостей — `D:`.

## 3. Сборка и тесты
Нужен Python 3.8+.
Запуск: `./run.sh <опции>` или `run.bat <опции>`.
Тесты: `PYTHONPATH=src python3 -m unittest discover -s tests`.

## 4. Примеры
```
./run.sh -p A -r tests/data/simple.txt -t -d 10        # полный граф
./run.sh -p A -r tests/data/simple.txt -t -d 1         # глубина 1
./run.sh -p A -r tests/data/simple.txt -t -d 10 -f E   # фильтр
./run.sh -p A -r tests/data/cycle.txt -t -d 10         # цикл
```
Вывод первой команды:
```
A -> B, C
B -> D
C -> D, E
D -> —
E -> —
```
